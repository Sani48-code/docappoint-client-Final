<div align="center">

A simple and modern backend API for booking doctor appointments with secure authentication and clean architecture.

---

# 🚀 What this project does

DocAppoint is a backend system where users can:

* View doctors
* Search and filter doctors
* Book appointments
* Manage their bookings securely

Doctors and appointments are stored in a MongoDB database and protected using authentication.

---

# 🛠️ Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* Better Auth

---

# 👨‍⚕️ Key Features

* Secure login using JWT
* Doctor listing with search & filter
* Appointment booking system
* Protected user booking routes
* Clean REST API structure
